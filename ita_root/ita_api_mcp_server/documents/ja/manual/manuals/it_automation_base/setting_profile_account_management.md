## アカウント管理
アカウント管理では、自身のアカウント編集、パスワード変更、二要素認証設定、トークン発行が行えます。
1. アカウント管理はログインユーザーのアイコンを選択して表示されるメニューから アカウント管理 を選択することにより設定できます。
Exastro IT Automation利用中は、メニュー - アカウント管理 は表示されません

### アカウント編集
1. アカウント編集（Personal info）より、Eメール、名、姓、所属、説明を変更することができます。

### パスワード変更
1. [Update]より、自身のパスワードを変更することができます。

### 二要素認証設定
1. [Set up Authenticator application]より、パスワードを入力してログイン後、二段階認証の設定を行うことができます。
