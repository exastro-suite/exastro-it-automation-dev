# Main Menu (Dashboard)
# Introduction
This document describes the ITA main menu (Dashboard).
# About the Main Menu
Widgets are displayed on the main menu.
The configuration information of a customized Dashboard is saved on the system for each user, so the customized settings remain available even when logging in from a different environment.
- No
     - Widget name
     - Description
     - Default
- 1
     - Menu group
     - | Panels for each menu group are displayed.
Clicking a panel takes you to the main menu of the specified menu group.
The "Menu group" widget cannot be deleted.
     - Shown
- 2
     - Movement
     - | The number of Movements registered for each orchestration is displayed as a pie chart.
Clicking the number in the "SUM" column or the chart takes you to the "Movement list" menu of each driver.
     - Shown
- 3
     - Work status
     - | The number of Conductor work items is displayed as a pie chart by status.
Clicking the number in the "CON" column takes you to the "Conductor work history" menu in the "Conductor" menu group.
     - Shown
- 4
     - Work results
     - | The number of Conductor work results is displayed as a pie chart by status.
Clicking the number in the "CON" column takes you to the "Conductor work history" menu in the "Conductor" menu group.
     - Shown
- 5
     - Work history
     - | The Conductor work history results are displayed as a bar chart by day.
Clicking the number in the "CON" column takes you to the "Conductor work history" menu in the "Conductor" menu group.
     - Shown
- 6
     - Menu set
     - You can create a set of menu groups separate from the main menu.
     - Hidden
- 7
     - Link
     - You can create a list of links.
     - Hidden
- 8
     - Scheduled work check
     - | Displays a list of Conductors with the status "Not executed (scheduled)".
You can check the instance ID, Conductor name, operation name, scheduled date/time, and the remaining time until the scheduled date/time.
     - Hidden
- 9
     - Image
     - You can paste an image.
     - Hidden
